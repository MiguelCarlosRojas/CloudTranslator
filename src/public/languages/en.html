Traducción a Inglés (Código: en)

Aprende a integrar el botón directo a inglés en tu frontend usando el microservicio en la nube https://cloudtranslator.onrender.com.

[ 01 // JAVASCRIPT_SDK ]

Integración con el SDK en el Frontend

El botón English ejecuta la traducción de todos los nodos de texto de la página en un solo micro-lote HTTP:

Código JavaScript
// Llamada directa a inglés
translator.translateToEnglish(); // Equivale a translator.translatePage("en")
Persistencia Automática: Se registra la cookie técnica cloud_translator_lang=en con duración de 365 días. Al recargar la página, el estado se preserva en 0ms.
[ 02 // REST_PAYLOAD ]

Ejemplo de Petición HTTP al Microservicio

POST /api/translate
POST https://cloudtranslator.onrender.com/api/translate
Content-Type: application/json

{
  "texts": [
    "Bienvenido a nuestra plataforma en línea",
    "Iniciar sesión con tu cuenta"
  ],
  "targetLanguage": "en"
}
Respuesta JSON (200 OK)
{
  "translatedTexts": [
    "Welcome to our online platform",
    "Log in with your account"
  ]
}
