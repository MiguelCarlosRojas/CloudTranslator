Términos del Servicio

Condiciones de uso y políticas de acceso para la API pública de https://cloudtranslator.onrender.com.

[ 01 // ACCEPTANCE ]

1. Aceptación de los Términos

Al acceder o utilizar la API de CloudTranslator a través de https://cloudtranslator.onrender.com, aceptas someterte a estos Términos de Servicio y a todas las directrices técnicas descritas en este portal.

[ 02 // FAIR_USE ]

2. Uso Responsable y Fair Use

El servicio está provisto para la internacionalización de sistemas web y aplicaciones corporativas:

  • No está permitido utilizar la API para actividades fraudulentas, ataques de denegación de servicio o saturación deliberada de la infraestructura.
  • Se recomienda el uso del atributo texts: [...] para enviar páginas web completas en una sola consulta de red.
  • Los desarrolladores deben respetar las cuotas razonables de tráfico del servidor en la nube.
[ 03 // AVAILABILITY ]

3. Disponibilidad del Servicio

El servicio se proporciona según disponibilidad técnica. Puedes verificar el estado en tiempo real en nuestra página de Estado del Servicio.
