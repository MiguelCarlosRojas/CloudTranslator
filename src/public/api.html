Servidor de Producción y Encabezados

Encabezado Valor Requerido Descripción
Content-Type application/json Obligatorio en peticiones con cuerpo (POST).
Accept application/json Indica al servidor que devuelva la respuesta en formato JSON.
Origin / CORS Cualquiera (*) Habilitado para consumo directo desde navegadores o servidores.
POST /api/translate Traducción individual o por lotes

Traducción de Texto (POST)

Envía un texto individual o una lista de textos mediante un payload JSON para traducir al idioma destino.

Parámetros del Payload (JSON)

Campo Tipo Obligatorio Descripción
text string Condicional Cadena individual a traducir (1 a 5,000 caracteres). Obligatorio si no se usa texts.
texts array[string] Condicional Lista de textos a traducir en una sola petición (1 a 1,000 elementos).
targetLanguage string Sí Código ISO de 2 letras del idioma de destino (ej: "en", "fr", "de").

Ejemplo de Petición (cURL)

curl -X POST "https://cloudtranslator.onrender.com/api/translate" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hola mundo desde CloudTranslator",
    "targetLanguage": "en"
  }'

Ejemplo de Respuesta (HTTP 200 OK)

{
  "translatedText": "Hello world from CloudTranslator"
}

Ejemplo con Lista de Textos (Batch)

curl -X POST "https://cloudtranslator.onrender.com/api/translate" \
  -H "Content-Type: application/json" \
  -d '{
    "texts": ["Inicio", "Servicios", "Contacto"],
    "targetLanguage": "en"
  }'
{
  "translatedTexts": [
    "Start",
    "Services",
    "Contact"
  ]
}
GET /api/translate Traducción rápida por Query Params

Traducción vía Query Params (GET)

Permite consultas directas mediante parámetros en la URL. Recomendado para pruebas rápidas en navegador.

curl -X GET "https://cloudtranslator.onrender.com/api/translate?text=Bienvenido&targetLanguage=en"
GET /api/languages Catálogo de idiomas soportados

Idiomas Disponibles

Devuelve el catálogo de códigos ISO soportados por el motor de traducción.

curl -X GET "https://cloudtranslator.onrender.com/api/languages"
{
  "success": true,
  "languages": [
    "en", "es", "fr", "de", "it", "pt", "ru", "ja", "zh-CN", "ar", "ko"
  ]
}
GET /api/health Monitor de disponibilidad

Estado de Salud (Healthcheck)

Utilizado por monitores de infraestructura para comprobar disponibilidad y tiempo de actividad.

curl -X GET "https://cloudtranslator.onrender.com/api/health"
{
  "success": true,
  "status": "ok",
  "uptime": 4520,
  "timestamp": "2026-09-28T22:00:00.000Z"
}
