[ G.01 // GATEWAY ]

Protocolo de Conexión & Encabezados

Condiciones y formatos requeridos para interactuar con la API REST.

[ 1.1 // BASE_URL ]

URL Base del Servidor

Todas las rutas son relativas a la dirección canónica en producción:

Base URL de Producción 
https://cloudtranslator.onrender.com/api

Se requiere comunicación estricta mediante HTTPS con TLS 1.3. Las solicitudes HTTP no cifradas se redirigen automáticamente a HTTPS.

[ 1.2 // HEADERS ]

Encabezados HTTP Requeridos

Encabezado Valor Requerido Detalle
Content-Type application/json Obligatorio (POST) Define que el cuerpo de la solicitud viaja en JSON estricto.
Accept application/json Opcional Garantiza que la respuesta se devuelva estructurada en JSON.
Access-Control-Allow-Origin * Automático Habilitado en todos los endpoints para clientes web frontend.
[ 1.3 // ERROR_SCHEMA ]

Esquema Estándar de Respuestas de Error

Cuando una solicitud falla por validación de parámetros (HTTP 400) o error interno (HTTP 500), el servidor responde con el siguiente formato JSON:

Esquema de Error JSON (HTTP 400 / 500) 
{
  "success": false,
  "error": "El idioma objetivo es requerido"
}
[ T.01 // POST_TRANSLATE ]

POST /api/translate

Endpoint principal para traducción de cadenas de texto y micro-lotes en una sola solicitud.

POST /api/translate Payload: texto individual

2.1 Traducción de Texto Simple

Cuerpo de la Petición (Request Body)

Propiedad Tipo Restricción Descripción
text string 1 a 5,000 caracteres Texto en lenguaje natural a traducir.
targetLanguage string Código ISO (ej. "en") Idioma de destino requerido.

Ejemplo de Solicitud (cURL)

Comando cURL (POST Texto Simple) 
curl -X POST "https://cloudtranslator.onrender.com/api/translate" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Infraestructura de microservicios en la nube",
    "targetLanguage": "en"
  }'

Respuesta Exitosa (HTTP 200 OK)

Respuesta JSON (HTTP 200 OK) 
{
  "translatedText": "Cloud microservices infrastructure"
}
POST /api/translate Payload: arreglo de textos

2.2 Traducción por Micro-lotes (Batch)

Permite enviar hasta 1,000 cadenas de texto en una sola conexión HTTP. Garantiza el orden idéntico de los elementos de entrada en la respuesta.

Cuerpo de la Petición (Request Body)

Propiedad Tipo Restricción Descripción
texts Array<string> 1 a 1,000 elementos Lista de cadenas a traducir de forma simultánea.
targetLanguage string Código ISO (ej. "en") Idioma de destino requerido.

Ejemplo de Solicitud (cURL)

Comando cURL (POST Lote de Textos) 
curl -X POST "https://cloudtranslator.onrender.com/api/translate" \
  -H "Content-Type: application/json" \
  -d '{
    "texts": ["Configuración", "Seguridad", "Facturación"],
    "targetLanguage": "en"
  }'

Respuesta Exitosa (HTTP 200 OK)

Respuesta JSON (HTTP 200 OK) 
{
  "translatedTexts": [
    "Settings",
    "Security",
    "Billing"
  ]
}
[ T.02 // GET_TRANSLATE ]

GET /api/translate

Consulta directa por cadena de consulta (Query String) para exploradores o clientes sin soporte de cuerpo en solicitudes.

Parámetro Ubicación Requerido Ejemplo
text Query param Sí ?text=Hola
targetLanguage Query param Sí &targetLanguage=en

Ejemplo de Solicitud (cURL)

Comando cURL (GET Query Params) 
curl -X GET "https://cloudtranslator.onrender.com/api/translate?text=Servicio&targetLanguage=en"

Respuesta Exitosa (HTTP 200 OK)

Respuesta JSON (HTTP 200 OK) 
{
  "translatedText": "Service"
}

[ V.02 // TEXT_TO_SPEECH ]

POST /api/tts

Genera locución vocal auditiva natural a partir de un texto plano, con calibración de tono (pitch), velocidad (rate) y entrega en audio base64 o URL de descarga directa.

Comando cURL (POST /api/tts) 
curl -X POST "https://cloudtranslator.onrender.com/api/tts" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Bienvenido al motor acústico de CloudTranslator",
    "voiceId": "es-ES-sofia",
    "lang": "es-ES",
    "rate": 1.0,
    "pitch": 1.0
  }'

Respuesta Exitosa (HTTP 200 OK)

Respuesta JSON (HTTP 200 OK) 
{
  "status": "success",
  "service": "CloudTranslator TTS Studio",
  "text": "Bienvenido al motor acústico de CloudTranslator",
  "lang": "es-ES",
  "voiceId": "es-ES-sofia",
  "audioBase64": "data:audio/wav;base64,UklGRi...",
  "streamUrl": "/api/tts/stream?text=Bienvenido...&voiceId=es-ES-sofia",
  "downloadUrl": "/api/tts/download?text=Bienvenido...&voiceId=es-ES-sofia",
  "format": "wav",
  "mimeType": "audio/wav"
}
[ V.03 // TTS_STREAMING ]

GET /api/tts/stream

Transmite el flujo binario de audio de forma continua en tiempo real mediante encabezados Content-Type: audio/wav sin requerir almacenamiento en disco local.

Comando cURL (GET /api/tts/stream) 
curl -X GET "https://cloudtranslator.onrender.com/api/tts/stream?text=Hola%20mundo&voiceId=es-ES-sofia" --output locucion.wav
[ V.04 // TTS_DOWNLOAD ]

GET /api/tts/download

Descarga directa del archivo de audio con cabecera Content-Disposition: attachment; filename="locucion-tts.wav".

Comando cURL (GET /api/tts/download) 
curl -L -O "https://cloudtranslator.onrender.com/api/tts/download?text=Hola%20mundo&voiceId=es-ES-sofia"
[ C.01 // VOICE_CLONING_AI ]

POST /api/voice-clone

Clonación de voz neuronal zero-shot a partir de una muestra auditiva de referencia (grabada con micrófono o subida en archivo). Extrae la frecuencia fundamental (F0), formantes acústicos y sintetiza el guion manteniendo el timbre original del usuario.

Comando cURL (POST /api/voice-clone) 
curl -X POST "https://cloudtranslator.onrender.com/api/voice-clone" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Esta es mi voz clonada mediante el motor de IA de CloudTranslator.",
    "audioSampleBase64": "data:audio/wav;base64,UklGRi...",
    "similarity": "high",
    "pitch": 1.0
  }'

Respuesta Exitosa (HTTP 200 OK)

Respuesta JSON (HTTP 200 OK) 
{
  "status": "success",
  "service": "CloudTranslator Voice Cloning AI",
  "text": "Esta es mi voz clonada mediante el motor de IA de CloudTranslator.",
  "similarity": "high",
  "detectedPitchHz": 142,
  "audioBase64": "data:audio/wav;base64,UklGRi...",
  "streamUrl": "/api/voice-clone/stream?sampleId=smp_78ab",
  "downloadUrl": "/api/voice-clone/download?sampleId=smp_78ab",
  "format": "wav",
  "mimeType": "audio/wav"
}
[ C.02 // CLONE_STREAM ]

GET /api/voice-clone/stream

Transmite en streaming continuo el audio con el timbre vocal clonado en tiempo real.

Comando cURL (GET /api/voice-clone/stream) 
curl -X GET "https://cloudtranslator.onrender.com/api/voice-clone/stream?sampleId=smp_78ab" --output voz-clonada.wav
[ C.03 // CLONE_DOWNLOAD ]

GET /api/voice-clone/download

Descarga directa física del archivo WAV sintetizado con la voz clonada por IA.

Comando cURL (GET /api/voice-clone/download) 
curl -L -O "https://cloudtranslator.onrender.com/api/voice-clone/download?sampleId=smp_78ab"
