Política de Privacidad

Transparencia en el procesamiento de solicitudes y cookies en https://cloudtranslator.onrender.com.

[ 01 // VOLATILE_PROCESSING ]

1. Cero Almacenamiento de Textos Traducidos

CloudTranslator procesa las solicitudes de traducción en memoria volátil de forma efímera. No almacenamos, no indexamos ni comercializamos los textos o párrafos enviados a través de nuestra API. Una vez entregada la respuesta JSON al cliente, los datos son purgados inmediatamente.

[ 02 // COOKIE_POLICY ]

2. Uso Exclusivo de Cookies Técnicas

El SDK del cliente únicamente crea la cookie cloud_translator_lang:

  • Contiene estrictamente el código del idioma deseado (ej: "en", "es").
  • No almacena direcciones IP, nombres, correos ni identificadores de rastreo publicitario.
  • Se preserva durante 365 días para evitar que el usuario deba re-seleccionar su idioma cada vez que navegue o recargue el sitio web.
[ 03 // TRANSPORT_SECURITY ]

3. Seguridad en la Transmisión

El 100% del tráfico se transfiere cifrado mediante HTTPS / TLS 1.3 garantizando que nadie en la red pueda interceptar el contenido traducido.
