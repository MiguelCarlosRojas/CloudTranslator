Traducción a Francés (Código: fr)

Configura traducciones instantáneas al francés en tu plataforma con el endpoint oficial https://cloudtranslator.onrender.com.

[ 01 // JAVASCRIPT_INTEGRATION ]

Implementación en JavaScript

Para traducir tu página completa al francés pasando el código ISO "fr":

Llamada SDK
translator.translatePage("fr");

Al completarse la consulta, la cookie cloud_translator_lang=fr se almacena en el navegador para mantener la preferencia en futuras visitas.

[ 02 // REST_CURL_EXAMPLE ]

Ejemplo con cURL

cURL CLI
curl -X POST https://cloudtranslator.onrender.com/api/translate \
  -H "Content-Type: application/json" \
  -d '{"text": "Hola, ¿cómo estás hoy?", "targetLanguage": "fr"}'

Respuesta JSON:

JSON 200 OK
{"translatedText": "Bonjour, comment vas-tu aujourd'hui?"}
