[ 01 // PREGUNTAS_FRECUENTES ]

Preguntas Frecuentes (FAQ)

¿Por qué la primera petición demora unos 25 segundos?

El microservicio opera en la capa en la nube de Render. Cuando no recibe tráfico continuo durante 15 minutos, el servidor entra en modo reposo para optimizar recursos. La primera petición activa el contenedor ("cold start") en aproximadamente 25 segundos, y a partir de ese momento todas las consultas responden de inmediato en menos de 300 ms.

¿Cómo optimiza CloudTranslator el consumo de red en mi navegador?

A diferencia de plugins tradicionales que disparan cientos de peticiones HTTP por cada párrafo, el cliente de CloudTranslator recopila todos los textos del DOM, los empaqueta en un arreglo JSON (texts: [...]) y realiza una única solicitud HTTP hacia el gateway en la nube.

¿Cómo funciona la memoria de traducción en caché?

Las frases traducidas se almacenan en la memoria local del cliente (localStorage) con un hash criptográfico. Si el usuario vuelve a cambiar al mismo idioma, los textos se leen instantáneamente en 0 ms sin generar tráfico hacia el servidor.

¿Cómo persiste la preferencia del usuario entre sesiones?

Al seleccionar un idioma, se registra la cookie cloud_translator_lang con vigencia de 365 días. Cualquier página del dominio que cargue el SDK restaurará automáticamente el idioma guardado sin intervención manual.

[ 02 // DIAGNÓSTICO_Y_RESOLUCIÓN ]

Resolución de Problemas (Troubleshooting)

Error HTTP 400: "El idioma objetivo es requerido"

Verifica que el cuerpo JSON de tu petición incluya el campo targetLanguage con un código ISO válido (por ejemplo "targetLanguage": "en" o "fr"). No utilices claves obsoletas como to.

Error HTTP 400: "El texto no puede estar vacío"

Debes enviar una cadena no vacía en el parámetro text o una lista con al menos un elemento en texts.

Error de CORS al consumir desde localhost u otro dominio

CloudTranslator tiene habilitado CORS universal (Access-Control-Allow-Origin: *) y métodos GET, POST, OPTIONS. Asegúrate de incluir el header Content-Type: application/json en solicitudes POST.
