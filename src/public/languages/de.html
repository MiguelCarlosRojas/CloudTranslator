Traducción a Alemán (Código: de)

Internacionaliza tu plataforma para usuarios de habla alemana mediante el microservicio https://cloudtranslator.onrender.com.

[ 01 // FRONTEND_INTEGRATION ]

Uso del Código "de"

Para traducir el frontend al alemán en una sola consulta asíncrona:

JavaScript
translator.translatePage("de");

El SDK actualiza la cookie cloud_translator_lang=de garantizando que el usuario continúe viendo el sitio en alemán tras recargar la página.

[ 02 // JSON_PAYLOAD_EXAMPLE ]

Ejemplo con JSON / REST

POST /api/translate
POST https://cloudtranslator.onrender.com/api/translate
Content-Type: application/json

{
  "texts": ["Bienvenido al panel de control", "Configuración del sistema"],
  "targetLanguage": "de"
}

Respuesta JSON:

JSON 200 OK
{
  "translatedTexts": ["Willkommen im Kontrollzentrum", "Systemeinstellungen"]
}
