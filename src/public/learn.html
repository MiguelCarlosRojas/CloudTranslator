Aprende a Integrar CloudTranslator

Tutoriales prácticos paso a paso para añadir traducción multilingüe automática en frontend y backend sin recargas de página. Para especificaciones de endpoints revisa Referencia de API.

[ 01 // FRONTEND_INTEGRATION ]

1. Integración en Frontend con el SDK JavaScript

El SDK para navegadores traduce el DOM de manera eficiente: agrupa las etiquetas de texto visibles y las envía en una sola consulta HTTP para no saturar la red.

Paso 1: Incluir el script

<script src="https://cloudtranslator.onrender.com/js/cloud-translator.js"></script>

Paso 2: Inicializar el traductor

const translator = new CloudTranslator({
  endpoint: "https://cloudtranslator.onrender.com/api/translate",
  useCookies: true,        // Guarda el idioma en la cookie cloud_translator_lang
  batchSize: 500,          // Límite de nodos de texto por consulta
  onStart: () => console.log("Traduciendo página..."),
  onComplete: () => console.log("Traducción completada")
});

// Traducir a inglés al pulsar un botón
document.getElementById("btn-en").onclick = () => {
  translator.translateToEnglish();
};

// Traducir a cualquier idioma por código ISO
document.getElementById("btn-fr").onclick = () => {
  translator.translatePage("fr");
};

// Restaurar al texto original
document.getElementById("btn-original").onclick = () => {
  translator.restoreOriginal();
};
[ 02 // BACKEND_NODEJS ]

2. Consumo desde Backend (Node.js)

Puedes invocar la API desde cualquier servicio Node.js utilizando el estándar fetch nativo o axios: 

async function traducirTexto(texto, idiomaDestino) {
  const response = await fetch("https://cloudtranslator.onrender.com/api/translate", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      text: texto,
      targetLanguage: idiomaDestino
    })
  });

  if (!response.ok) {
    const errorData = await response.json();
    throw new Error(errorData.error || "Fallo en la traducción");
  }

  const data = await response.json();
  return data.translatedText;
}

// Ejemplo de uso:
traducirTexto("Hola mundo", "en")
  .then(res => console.log("Resultado:", res)) // "Hello world"
  .catch(err => console.error(err));
[ 03 // BACKEND_PYTHON ]

3. Consumo desde Python

Integración sencilla en scripts o APIs desarrolladas con FastAPI, Flask o Django: 

import requests

def traducir(texto: str, idioma_destino: str) -> str:
    url = "https://cloudtranslator.onrender.com/api/translate"
    payload = {
        "text": texto,
        "targetLanguage": idioma_destino
    }
    headers = {"Content-Type": "application/json"}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()
    return response.json().get("translatedText")

# Ejecución
print(traducir("Servicio de traducción en la nube", "en"))
# Salida: "Cloud translation service"
[ 04 // BEST_PRACTICES ]

4. Buenas Prácticas de Arquitectura

  • Usa el modo Batch: Si tienes que traducir una lista de elementos (menús, productos, alertas), envíalos en el arreglo texts: [...] en vez de hacer 20 llamadas separadas.
  • Manejo del Cold Start: En caso de que la instancia esté en reposo, implementa un reintento con backoff exponencial o una alerta visual de carga.
  • Exclusión de elementos: Para evitar que se traduzcan nombres de marca, códigos o fórmulas, añade la clase notranslate o el atributo translate="no" al elemento HTML.
