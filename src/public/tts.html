Consumo Programático: POST /api/tts

Integra la síntesis vocal directamente en tus aplicaciones o microservicios enviando una consulta JSON:

cURL - Síntesis de Texto a Voz 
curl -X POST https://cloudtranslator.onrender.com/api/tts \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hola, este es un mensaje sintetizado con CloudTranslator",
    "lang": "es",
    "rate": 1.0,
    "pitch": 1.0
  }'
