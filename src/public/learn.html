Aprende a Integrar CloudTranslator

Guía técnica integral paso a paso. Aprende los fundamentos arquitectónicos, la integración en el navegador con el SDK JavaScript y el consumo directo en servidores (Node.js, Python, cURL) con micro-lotes y tolerancia a fallos.

[ 00 // ARCHITECTURE_OVERVIEW ]

0. ¿Cómo Funciona la Integración?

CloudTranslator opera bajo una arquitectura desacoplada y orientada a microservicios. Puedes integrarlo según el escenario de tu aplicación:

Enfoque Mecanismo Casos de Uso Ideales Ventajas Clave
Frontend (SDK JS) Inclusión directa de cloud-translator.js en el HTML del cliente. Sitios web estáticos, landings, blogs, paneles SPA donde se requiere traducir la interfaz completa en vivo. Cero backend propio requerido, traduce el DOM sin recargas, maneja cookies automáticamente.
Backend (REST API) Invocación vía HTTP POST a /api/translate desde tu servidor. APIs, generación de correos electrónicos, catálogos en base de datos, tareas asíncronas o microservicios. Control total del flujo de datos, ocultamiento de lógica de negocio, soporte para lotes masivos.
[ 01 // FRONTEND_INTEGRATION ]

1. Integración en Frontend con el SDK JavaScript

El SDK para navegadores examina el árbol DOM, recolecta de manera transparente todos los nodos de texto visibles respetando elementos interactivos (botones, enlaces, inputs) y envía las cadenas agrupadas en un solo paquete HTTP para optimizar el consumo de red y no bloquear la interfaz.

Paso 1: Incluir el Script en tu HTML

Añade la etiqueta <script> al final del <body> o dentro de <head>:

HTML / ETIQUETA SCRIPT CDN 
<script src="https://cloudtranslator.onrender.com/js/cloud-translator.js"></script>

Paso 2: Opciones de Inicialización

Al instanciar new CloudTranslator(options), dispones de los siguientes parámetros configurables:

Parámetro Tipo Valor por Defecto Descripción
endpoint string "/api/translate" URL absoluta o relativa del servicio de traducción. En producción usa: https://cloudtranslator.onrender.com/api/translate.
useCookies boolean true Si es true, guarda el idioma seleccionado en la cookie del navegador para mantener la preferencia en futuras visitas.
batchSize number 500 Número máximo de nodos de texto enviados por petición HTTP.
onStart function null Callback invocado al iniciar la traducción (ideal para mostrar spinners o barras de carga).
onComplete function null Callback invocado cuando todos los textos del DOM han sido reemplazados exitosamente.
onError function null Callback que recibe el error en caso de fallo de red o tiempo de espera agotado.

Paso 3: Código de Ejemplo Funcional Completo

Copia y pega este archivo HTML en tu computadora para probar la traducción en tiempo real:

HTML COMPLETO / EJEMPLO CLIENTE MÍNIMO 
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi Sitio Multilingüe</title>
</head>
<body>
  <!-- Barra de selección de idioma -->
  <header>
    <button id="btn-en">English</button>
    <button id="btn-fr">Français</button>
    <button id="btn-de">Deutsch</button>
    <button id="btn-original">Restaurar Original</button>
    <span id="loading-indicator" style="display: none; margin-left: 10px;">Traduciendo...</span>
  </header>

  <main>
    <h1>Bienvenido a nuestra plataforma global</h1>
    <p>Ofrecemos soluciones avanzadas de software empresarial en la nube.</p>
    <p class="notranslate">Esta marca CloudTranslator no se traduce nunca.</p>
  </main>

  <!-- Inclusión del SDK -->
  <script src="https://cloudtranslator.onrender.com/js/cloud-translator.js"></script>
  <script>
    // 1. Inicialización del traductor
    const translator = new CloudTranslator({
      endpoint: "https://cloudtranslator.onrender.com/api/translate",
      useCookies: true,
      batchSize: 500,
      onStart: () => {
        document.getElementById("loading-indicator").style.display = "inline";
      },
      onComplete: () => {
        document.getElementById("loading-indicator").style.display = "none";
      },
      onError: (err) => {
        document.getElementById("loading-indicator").style.display = "none";

      }

    // 2. Conectar eventos de botones
    document.getElementById("btn-en").onclick = () => translator.translateToEnglish();
    document.getElementById("btn-fr").onclick = () => translator.translatePage("fr");
    document.getElementById("btn-de").onclick = () => translator.translatePage("de");
    document.getElementById("btn-original").onclick = () => translator.restoreOriginal();
  </script>
</body>
</html>

Paso 4: Exclusión de Elementos y Marcas

Para proteger nombres propios, términos técnicos, marcas comerciales o bloques de código que no deben traducirse, añade la clase notranslate o el atributo HTML estándar translate="no":

HTML / EXCLUSIÓN DE ELEMENTOS

<!-- Opción B: Mediante atributo estándar HTML5 -->

  <p>API_KEY_SECRET = "sk_live_9941a87b"</p>
</div>
[ 02 // BACKEND_NODEJS ]

2. Consumo desde Backend (Node.js & TypeScript)

Invoca la API desde cualquier servidor Node.js, Express, Next.js, Fastify o NestJS mediante el estándar nativo fetch sin requerir librerías externas.

2.1 Traducción de Texto Individual

NODE.JS / TEXTO SIMPLE (FETCH) 
async function traducirTexto(texto, idiomaDestino) {
  const url = "https://cloudtranslator.onrender.com/api/translate";
  const respuesta = await fetch(url, {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      text: texto,
      targetLanguage: idiomaDestino
    })
  });

  if (!respuesta.ok) {
    const errorJson = await respuesta.json().catch(() => ({}));
    throw new Error(errorJson.error || `HTTP Error ${respuesta.status}`);
  }

  const datos = await respuesta.json();
  return datos.translatedText; // Cadena traducida
}

// Ejemplo de uso:
traducirTexto("Servicio de traducción en tiempo real", "en")
  .then(res => console.log("Resultado:", res)) // "Real-time translation service"
  .catch(err => console.error("Error:", err.message));

2.2 Traducción de Lotes Masivos (Micro-batch)

Para catálogos, menús o notificaciones compuestas, envía el arreglo texts para procesar hasta 1,000 cadenas en una sola llamada:

NODE.JS / TRADUCCIÓN POR LOTES (BATCH) 
async function traducirLote(listaTextos, idiomaDestino) {
  const url = "https://cloudtranslator.onrender.com/api/translate";
  const respuesta = await fetch(url, {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      texts: listaTextos,
      targetLanguage: idiomaDestino
    })
  });

  const datos = await respuesta.json();
  if (!datos.success) {
    throw new Error(datos.error || "Error al procesar lote");
  }

  return datos.translatedTexts; // Array con orden garantizado
}

// Ejemplo:
traducirLote(["Inicio", "Configuración", "Cerrar Sesión"], "en")
  .then(resultado => console.log(resultado));
  // Salida: ["Home", "Settings", "Log Out"]

2.3 Manejo Resiliente del "Cold Start" en Render

En la infraestructura gratuita de Render, la máquina entra en suspensión tras 15 minutos de inactividad. El primer contacto tardará entre 30 y 45 segundos mientras el servidor inicia. Implementa un reintento con retardo (backoff):

NODE.JS / CLIENTE RESILIENTE CON RETRY 
async function traducirConReintento(texto, idioma, maxIntentos = 3) {
  const url = "https://cloudtranslator.onrender.com/api/translate";

  for (let intento = 1; intento <= maxIntentos; intento++) {
    try {
      const res = await fetch(url, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ text: texto, targetLanguage: idioma }),
        signal: AbortSignal.timeout(50000) // 50s de margen para Cold Start
      });

      if (res.ok) {
        const data = await res.json();
        return data.translatedText;
      }
    } catch (err) {
      console.warn(`Intento ${intento} fallido. Esperando reactivación...`);
      if (intento === maxIntentos) throw err;
      await new Promise(r => setTimeout(r, 4000 * intento));
    }
  }
}

3. Consumo desde Python

Integración directa para scripts de datos o APIs construidas con FastAPI, Flask, Django o scripts de procesamiento batch:

PYTHON / MÓDULO REQUESTS (TEXTO Y BATCH) 
import requests
from typing import List, Union

API_URL = "https://cloudtranslator.onrender.com/api/translate"

def traducir(contenido: Union[str, List[str]], idioma_destino: str) -> Union[str, List[str]]:
    headers = {"Content-Type": "application/json"}
    
    # Detección automática: texto individual o lote
    if isinstance(contenido, list):
        payload = {"texts": contenido, "targetLanguage": idioma_destino}
    else:
        payload = {"text": contenido, "targetLanguage": idioma_destino}
    
    # Timeout amplio para absorber posibles cold starts
    response = requests.post(API_URL, json=payload, headers=headers, timeout=60)
    response.raise_for_status()
    data = response.json()
    
    if isinstance(contenido, list):
        return data.get("translatedTexts", [])
    return data.get("translatedText", "")

# Pruebas de ejecución:
print(traducir("Servicio de traducción en la nube", "en"))
# Salida: "Cloud translation service"

print(traducir(["Facturación", "Inventario", "Reportes"], "fr"))
# Salida: ["Facturation", "Inventaire", "Rapports"]
[ 04 // CLI_AUTOMATION ]

4. Automatización con cURL y Terminal

Puedes consumir el microservicio directamente desde scripts de terminal Bash, pipelines de GitHub Actions o tareas programadas Cron:

TERMINAL / CURL Y JQ 
# 1. Traducción directa e impresión limpia del resultado con jq
curl -s -X POST "https://cloudtranslator.onrender.com/api/translate" \
  -H "Content-Type: application/json" \
  -d '{"text": "Despliegue completado con éxito", "targetLanguage": "en"}' \
  | jq -r '.translatedText'
# Salida: Deployment completed successfully
[ 05 // STATUS_CODES_TROUBLESHOOTING ]

5. Códigos de Respuesta y Diagnóstico de Errores

El gateway de CloudTranslator emite códigos de estado HTTP estándar acompañados de un mensaje aclaratorio en JSON:

Código HTTP Estado Causa Frecuente Acción Recomendada
200 OK Exitoso Petición procesada correctamente. Consumir translatedText o translatedTexts.
400 Bad Request Error de Validación Falta targetLanguage o el cuerpo no contiene text ni texts. Revisar el formato JSON y asegurarse de incluir el encabezado Content-Type: application/json.
500 Internal Error Fallo del Motor Problema temporal de comunicación con el motor subyacente. Implementar reintento automático tras 2 o 3 segundos.
503 Unavailable Instancia Despertando La máquina gratuita de Render está reactivándose tras suspensión. Esperar 30 segundos y reintentar la solicitud.
